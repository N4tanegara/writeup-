# writeup ku belajar-
Selamat datang! Repository ini adalah tempat saya menyimpan seluruh dokumentasi, catatan, dan write-up dari tantangan PicoCTF yang berhasil saya selesaikan. 

Saya membuat repository ini sebagai media pembelajaran pribadi, arsip kenang-kenangan, sekaligus bukti perjalanan saya dalam mendalami dunia cybersecurity dari tingkat paling dasar.

Saat pertama kali belajar CTF, saya menyadari bahwa dokumentasi adalah kunci. Setiap kali berhasil mendapatkan flag, saya mengabadikan langkah-langkah penyelesaiannya di sini agar tidak lupa. Catatan ini berfungsi sebagai pengingat di masa depan saat saya ingin mengulas kembali materi yang pernah dipelajari, sekaligus portofolio kecil atas proses belajar yang telah saya lewati.
